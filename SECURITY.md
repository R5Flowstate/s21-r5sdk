# Security

Report vulnerabilities privately through GitHub Security Advisories on
this repository. Do not open a public issue for an unreleased vulnerability.

This project is a detour layer over Apex Legends binaries. Reports that need
a private channel:

- remote code execution on a player client from a hostile server
- unauthenticated dedicated-server takeover or host shutdown
- credential, token or key leakage in the shipped tree

Do not include live operator secrets, player account identifiers, or
install paths in a public post.
